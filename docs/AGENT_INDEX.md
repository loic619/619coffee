## Reading these cheaply

`workflow_activity.json` is 26 KB and `workflows_inventory.json` is 38 KB. Reading both
into context costs roughly 16,000 tokens to learn facts a one-line query answers in 150.
Query them; do not open them:

```sh
python3 -c "import json; d=json.load(open('frontend/public/data/workflow_activity.json')); \
print([(w['name'], w['failure'], w['runs']) for w in d['workflows'] if w['failure']])"
```
